# Antigravity 简体中文补丁

支持 Windows Antigravity **2.13.0**（兼容 2.12.2）。提供 2,893 条翻译词条、3,822 处经过原文校验的替换，以及设置显示和原生菜单汉化。第三方非官方项目，与 Google 无隶属关系。

## 使用

1. 安装 Node.js 18 或更新版本，确保 `node` 在 PATH 中。
2. 完全退出 Antigravity（包括托盘）。
3. 双击 `build.bat`，从本机原版安装中离线提取资源并构建。
4. 双击 `apply_chinese.bat`，然后启动 Antigravity。
5. 恢复英文：退出应用后双击 `restore_english.bat`。

自定义安装路径：`node build.cjs --app-path "D:\Antigravity"`，然后 `powershell -ExecutionPolicy Bypass -File switch-language.ps1 -AppPath "D:\Antigravity" -Mode Chinese`。

构建产物仅保存在 `.local-build`，不应上传。重新构建请通过 `--output` 指定新的空目录，安装时通过 `-BuildDirectory` 指定该目录。

## 修复与覆盖范围

旧汉化中的中文描述缺失结束引号，导致主脚本语法错误及启动黑屏。本补丁按照经过核对的位置替换字符串，使用 JSON 转义、校验模板占位符，并在写入前检查整个脚本语法。

覆盖会话界面、常规/应用/外观/模型/自定义/浏览器设置、错误提示、权限选项、项目与工作区下拉菜单、工具执行状态与原生菜单。产品与模型名称、代码示例、用户内容及插件自带文档保持原样。动态服务端文案可能随服务更新出现新英文；不承诺任何未来版本全覆盖。

## 安全与恢复

仅接受指定版本的原始文件哈希或已知补丁哈希，不覆盖未知升级。安装前验证全部文件，应用运行时拒绝安装。每次切换均备份至安装目录 `resources/zh-backups`，失败尝试回滚。不清空用户配置、会话或账户。

仓库只提供构建脚本、翻译字典和小范围补丁定位数据，不分发应用程序、完整官方前端或用户数据。需要用户自行安装正版应用。修改后重新构建前建议运行 `node --test`。

## 已知独立问题

此前 2.12.2 在本机下载官方 Playwright 1.57.0 浏览器驱动时返回 404；当时英文原版同样出现。此问题尚未在 2.13.0 中单独复验。这不属于汉化造成的黑屏，补丁不会修改浏览器驱动版本或网络设置。
